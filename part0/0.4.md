flowchart TD
Start([User Fills Out Form]) --> Submit[Click Submit Button]
Submit --> ClientVal{Client-Side<br>Validation?}

    ClientVal -- Invalid --> ShowClientErr[Highlight Missing/Invalid Fields]
    ShowClientErr --> Start

    ClientVal -- Valid --> DisableBtn[Disable Submit Button & Show Spinner]
    DisableBtn --> SendAPI[POST Data to Server API]

    SendAPI --> ServerVal{Server-Side<br>Validation & Auth?}
    ServerVal -- Error 400/422 --> ShowServerErr[Re-enable Button & Display API Error]
    ShowServerErr --> Start

    ServerVal -- Valid 200 OK --> SaveDB[(Save Record to Database)]
    SaveDB --> Success([Redirect or Show Success Message])

sequenceDiagram
autonumber
actor User
participant Browser as Browser (SPA Client)
participant CDN as UI Server / CDN
participant API as Backend API

    Note over User, API: Phase 1: Initial Application Load
    User->>Browser: Navigates to app URL
    Browser->>CDN: GET / (index.html)
    CDN-->>Browser: Returns HTML shell + JS/CSS bundles
    Browser->>Browser: Executes JS & mounts UI framework
    Browser->>API: GET /api/initial-data (JSON)
    API-->>Browser: 200 OK (JSON payload)
    Browser-->>User: Renders initial view

    Note over User, API: Phase 2: Subsequent Navigation (No Reload)
    User->>Browser: Clicks internal link / route
    Browser->>Browser: Intercepts route & updates URL
    Browser->>API: GET /api/new-view-data (JSON)
    API-->>Browser: 200 OK (JSON payload)
    Browser->>Browser: Updates DOM components
    Browser-->>User: Displays updated view
